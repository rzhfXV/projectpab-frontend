# Android Booking App (Frontend)

This repository contains the frontend application for the Booking system. It is a native Android application built with Kotlin and follows modern Android development practices.

## Related Repository

- **Backend API:** [Project Pab - Backend](https://github.com/rzhfXV/projectpab-backend/tree/experimental) 

## Tech Stack

- **Language:** Kotlin
- **UI & Layout:** XML Layouts, ViewBinding, Material Components
- **Network:** Retrofit2, OkHttp3, Gson
- **Asynchronous Programming:** Kotlin Coroutines
- **Navigation:** Jetpack Navigation Component
- **Local Storage:** DataStore Preferences (for JWT tokens)
- **Image Loading:** Glide, CircleImageView
- **Loading Effects:** Facebook Shimmer (Skeleton UI)

## Prerequisites

- Android Studio (latest version recommended)
- Android SDK (Target SDK 36, Min SDK 24)
- Java Version 11

## Setup & Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/rzhfXV/projectpab-frontend/tree/ver1.2
   ```
2. Open the project in **Android Studio**.
3. Let Gradle sync the project dependencies automatically.
4. Ensure your API Base URL is correctly configured in the networking module to communicate with the Backend.
5. Build and run the application on an emulator or a physical device.
